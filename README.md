# Task Manager з Backup

## Функціонал
### Задачі
- Створення, перегляд, редагування та видалення задач (CRUD).
- Поля задачі: назва, опис, дата виконання, пріоритет, статус виконання та підзадачі.
- Пріоритети: low, medium, high.
- Фільтрація задач за пріоритетом.
- Сортування за датою виконання.
- Позначення задачі та окремих підзадач як виконаних.

### Backup / Restore
- Експорт усіх задач у JSON.
- Імпорт задач із JSON-файлу.
- Перегляд списку резервних копій.
- Відновлення вибраної копії та видалення копій.
- Автоматична резервна копія під час запуску застосунку, якщо остання була створена 24 або більше годин тому.
- Зберігаються останні 10 внутрішніх резервних копій.

### Аналітика
- Загальна кількість задач.
- Кількість виконаних та невиконаних задач.
- Прострочені задачі.
- Продуктивність у відсотках.
- Середній час виконання завершених задач.

Для розрахунку середнього часу додано поля `createdAt` та `completedAt`. Час рахується від створення задачі до її позначення як виконаної.

## Основні файли

- `main.dart` - запускає застосунок, ініціалізує Hive, реєструє адаптер та відкриває box `tasks`.
- `task.dart` - модель задачі з полями, які зберігаються в Hive.
- `task_adapter.dart` - перетворює об'єкт Task у формат Hive та назад. Адаптер написаний вручну, тому генерація коду не потрібна.
- `home_screen.dart` - головний інтерфейс із трьома розділами: задачі, статистика та резервні копії.
- `task_form.dart` - форма введення даних задачі та керування підзадачами.
- `backup_manager.dart` - створення JSON, імпорт, список, відновлення та очищення старих копій.
- `task_analytics.dart` - підрахунок статистики.

## Використані пакети

- `hive` та `hive_flutter` - локальна база даних.
- `path_provider` - отримання папки документів застосунку.
- `file_picker` - вибір JSON для імпорту та збереження експортованого файлу.
- `flutter` - інтерфейс застосунку.
